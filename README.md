# 🌡️ Temperature Converter

A simple and colorful temperature converter built using **HTML, CSS, and JavaScript**. This project allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin through a clean and user-friendly interface.

## ✨ Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Live temperature conversion
- Input validation for empty and invalid values
- Prevents temperatures below absolute zero
- Colorful gradient design
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Structures the application
- **CSS3** – Adds styling, gradients, and responsive design
- **JavaScript** – Handles conversion formulas, validation, and DOM updates

## 🌡️ Conversion Formulas

| Conversion | Formula |
|---|---|
| Celsius to Fahrenheit | (C × 9/5) + 32 |
| Fahrenheit to Celsius | (F − 32) × 5/9 |
| Celsius to Kelvin | C + 273.15 |
| Kelvin to Celsius | K − 273.15 |
| Fahrenheit to Kelvin | (F − 32) × 5/9 + 273.15 |
| Kelvin to Fahrenheit | (K − 273.15) × 9/5 + 32 |

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/temperature-converter.git
   ```

2. Open the project folder:

   ```bash
   cd temperature-converter
   ```

3. Open `index.html` in your browser.

No additional installations or dependencies are required.

## 📸 How It Works

1. Enter a temperature.
2. Select the unit to convert from.
3. Select the unit to convert to.
4. View the converted temperature instantly.
